Approach

How I work.

The habits behind the repositories above. They are the same habits I bring to a team.

01

Measure, don't assert.

Every benchmark names the machine, the command and the noise floor. If a change does not move a number, it does not ship. If it moves a number the wrong way, that is reported too.

02

Offline by default.

Tests and demos run without API keys or network, against deterministic fakes, so CI is honest, fast and reproducible by anyone who clones the repo.

03

Read the paper, then write the code.

Raft from Figure 2. HNSW from Malkov and Yashunin. BPE from the merge rule. Frameworks are easier to use well once you have built what they hide.

04

Ship the whole thing.

A platform for 100+ researchers, a serverless engine for 10,000 accounts, an app on the App Store: discovery to rollout to documentation to handoff.
